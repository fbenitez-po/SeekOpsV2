# S-03-PROYECTO-ASIGNAR-USUARIOS — Asignar usuarios a proyecto

> Modal para asignar usuarios a un proyecto con sus roles.

**Componentes:**
- Tabla de usuarios disponibles con checkboxes
- Selector de rol (Seeker/Gestor) para cada usuario
- Botones: Guardar asignaciones | Cancelar

**Acciones:** Guardar → PUT /projects/:id/assign-users → Email a usuarios
